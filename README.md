# PPT to PDF Converter
This is a tool using Python + comtypes to automatically batch convert PowerPoint files into PDFs.

## Features
Supports .ppt and .pptx formats

Can convert an entire folder of files at once

Allows users to custom enter source and output folder paths

Output PDF file names are identical to original PPT file names

## Installation

Install Python 3.10+

Install required packages:

Bash
pip install comtypes
## Notes
Requires Windows + Microsoft PowerPoint installed

If you don't have PowerPoint, you can use LibreOffice instead (requires modifying the code yourself)

Please ensure the input path is correct, otherwise the program cannot find the files
